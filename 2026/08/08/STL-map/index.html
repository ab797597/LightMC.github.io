C++STL容器：map&set

map

定义

map<Typename1, Typename2> Yourtype;
值得注意的一点是，map重载了operator[]，可以跟数组一样当下标用。
一个使用map的实例：
map<int, int> ty;
值得注意的是，当创建字符串对整数的映射是，只能用string，而不能用int
map中不存在相同元素

插入与删除

可直接通过下标访问，如mp["aaa"]=100;
向map中插入一个pair即可插入元素，如mp.insert[pair<string,int>("aaa",100)];

  • mp.erase(key)将会删除所有键值为key的元素，返回值为删除元素的数量
  • mp.erase(pos)删除迭代器为pos的元素，迭代器必须有意义且不可为空
  • mp.erase(first,last)删除迭代器在[first,last)内的所有元素
  • mp.clear()清空整个容器
    在用下标访问的过程中，尤其需要注意的是，如果map中不存在下标，将会直接创建一个下标，对应默认键值，当空下标过多时，将会极大地影响map的效率，所以一般使用mp.find()查找元素

查询

  • mp.count(x)返回键为x的元素个数，对数复杂度
  • mp.find(x)返回x的迭代器，否则返回end()
  • mp.lower_bound(x)返回首个大于等于给定键的元素的迭代器
  • mp.upper_bound(x)返回首个大于给定键的元素的迭代器，若不存在这样的迭代器，返回end()
  • mp.empty()返回容器是否为空
  • mp.size()返回容器中元素个数

map用于存储复杂状态

set

定义

值得注意的是，与map不同，set中不会出现指相同的元素（这里可没有键）

插入与删除

  • insert(x) 将元素x插入到set中，返回值为pair<iterator,bool>iterator代表迭代器，bool代表是否插入成功
  • erase(x)删除值为x的元素
  • erase(pos)删除迭代器为pos的元素，要求迭代器必须合法
  • erase(first,last)删除迭代器在[first,last)范围内的所有元素
  • clear()清空set

迭代器

  1. begin()指向首元素的迭代器
  2. end()指向末端占位符的迭代器，注意没有元素
  3. rbegin()指向末元素
  4. rend()指向容器首的前一个元素

查找

  • count(x)返回键为x的元素数量
  • find(x)返回x的迭代器，否则返回end()
  • lower_bound(x)返回首个大于等于给定键的元素的迭代器
  • upper_bound(x)返回首个大于给定键的元素的迭代器，若不存在这样的迭代器，返回end()
  • empty()返回容器是否为空
  • size()返回容器中元素个数
    注意，lower_bound和upper_bnoud为对数时间复杂度
    set中没有nth_element，而使用algorithm中的该函数时间复杂度为O(n)

set于贪心的应用

用于找出并删除最小的大于某个值的元素，这种操作使用set可以轻松完成

遍历容器

可以用迭代器来遍历set或map容器的所有元素

时间复杂度O(n)
